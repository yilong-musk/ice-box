# App icons

Brand icons for the simulated Android application list in the Live Demo. The
SVGs come from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons)
and are redistributed under the Apache License 2.0 (see `LICENSE`). GitHub, X,
and TikTok are wrapped in a neutral tile so they stay visible in both themes.

The marks remain trademarks of their owners. They identify the mocked
applications only; this project is not affiliated with any of these services.
