## Default Permission

Prepare, start, stop, and inspect the platform VPN tunnel.

#### This default permission set includes the following:

- `allow-prepare`
- `allow-start`
- `allow-stop`
- `allow-reload`
- `allow-status`
- `allow-shared-dir`
- `allow-memory`
- `allow-device-status`
- `allow-request-battery-exemption`
- `allow-open-network-settings`
- `allow-open-vpn-settings`
- `allow-open-https-url`
